# 🎮 Code Quest – Snake and Ladders Quiz Game

Code Quest is a fun and interactive Snake and Ladders game combined with programming quizzes.
Players must answer coding-related questions correctly to roll the dice and move across the board while competing against an AI opponent.

---

## ✨ Features

* 🎲 Fully animated dice system
* 🐍 Classic Snake and Ladders gameplay
* 💻 Coding quiz integration
* 🧠 Multiple programming languages

  * Python
  * Java
  * C++
* 📈 Difficulty levels

  * Easy
  * Medium
  * Hard
* 🤖 AI opponent
* 👤 Avatar selection system
* 🔐 Login and Signup pages
* 🎨 Responsive and modern UI design
* 🏆 Replay option after winning

---

## 🚀 How to Run the Project

1. Download or clone the repository

```bash
git clone https://github.com/your-username/code-quest.git
```

2. Open the project folder

3. Run `signup.html` in your browser

4. Create an account and start playing

---

## 🎯 Gameplay Rules

* Answer the quiz question correctly to unlock the dice
* Roll the dice to move on the board
* Landing on a ladder moves you up
* Landing on a snake moves you down
* First player to reach 100 wins
